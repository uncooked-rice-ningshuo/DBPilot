# Agent 基础能力与聊天体验

按用户授权优先完成 AI：保留单工作区 Agent 与受控工具执行链。首先落实现有数据库工具、可验证的待办工具和内置命令说明，再考虑 Skill，最后 MCP；后两者不作为本轮门槛。

规则查看/编辑使用右侧抽屉，继续复用已安装的 shadcn Dialog/Radix 焦点和 Escape 行为。聊天顶部提供固定的新对话入口；用户消息右对齐、助手左对齐，内容按自身宽度排布。任务工具记录与回答区分，待办展示为模型维护的计划，不能替代真实执行证据。

常用 Linux 命令先提供内置参考工具（ls、pwd、head、tail、grep、wc），明确只返回固定说明，不执行命令、不读取主机文件。这样可立即支持命令理解且不额外引入路径授权、跨平台 Shell 和凭据泄漏边界；未来真实文件工具必须另设 Runtime 授权入口。

待办工具使用严格参数校验、条目与长度预算、最多一个进行中项；每轮隔离，仅供任务跟踪。所有工具仍有审计、调用次数和取消预算。对话恢复与 TTL 故障继续以执行历史为准，不自动重放写入。

验证以工具单测、现有 Agent 集成回归及隔离浏览器交互为证据；模拟模型不算真实供应商联调。

## 恢复与模型输出增量

会话快照保留最近32轮；历史淘汰与请求去重分离。独立请求账本保留已处理ID，过期ID重试返回410，不重新调用模型；账本最多100,000条，满后保守拒绝新任务。持久状态与父子分支同事务保存。重启后的未完成任务标为中断，没有后台恢复执行。

模型使用标准Chat Completions SSE，逐步更新当前回答；Web与Desktop仍通过只读状态轮询观察。解析器处理UTF-8与跨chunk帧、工具参数分片、1MiB传输/16,000字符回答预算，必须收到完成原因与[DONE]。只有完整且校验通过的工具消息才进入Runtime执行链；断流、length/content_filter、重复/缺失工具片段均停止，不重发模型请求。单模型调用60秒，Agent总时限5分钟。

协议依据：[DeepSeek Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/)；2026-10-07核对其SSE delta/tool_calls/finish_reason契约。兼容接口可直接返回单个JSON回答，不再次发送请求。

模型配置新增独立工具能力测试，发送固定测试句、强制无副作用的dbpilot_probe工具响应，只验证返回格式，不执行工具、不读取数据库、不保存到对话。模型列表成功不再冒充所选模型的工具能力验证。UI显示静态安全错误，不透传供应商响应体或认证头。
