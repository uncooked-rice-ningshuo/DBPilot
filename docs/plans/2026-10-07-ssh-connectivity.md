# 单跳SSH连接闭环

在完成Agent基础能力和TLS后，继续架构B阶段的连接能力。只提供数据库TCP转发，不提供Shell、远程命令、SFTP或模型权限修改。

连接可选SSH主机/端口/用户名/密码与必须的SHA256主机指纹。凭据在配置Secret Store加密，不返回给界面或Agent。首次指纹由用户从可信渠道核验后填写，不自动接受首次看到的主机密钥；变化直接阻断。先实现密码认证，私钥认证作为后续增量。

每个数据库操作取得独立隧道租约：ssh2验证指纹和认证，创建仅绑定127.0.0.1的临时转发端口，Driver通过该端口连接；结束/超时/取消释放租约。TLS仍按数据库原逻辑主机或显式证书名验证。隧道断开关闭转发socket，交给现有数据库失败/未知写入结果处理，不连接重放。无池化或自动重连，减少首版状态复杂度。

测试使用实际ssh2协议服务器和真实PG/MySQL测试数据库，覆盖正确指纹、错误指纹、错误认证、真实查询、TLS经隧道身份保持及断开。模拟业务协议不算数据库验收；不使用用户保存连接进行写入测试。
