# Agent 连接草稿

先完成固有工具，无Skills/MCP。request_connection严格只接受引擎、名称、主机、端口、数据库、用户名，不接受密码、路径、TLS/SSH/权限字段；不调用Runtime或增加授权。工具结果明确未创建。

共享聊天显示查看草稿入口，任务结束后用户点击打开现有连接表单。网络草稿默认开启TLS，密码空白；SQLite路径由用户填写。用户明确测试/保存后才建立连接。当前轮及后续追问授权保持原集合，开始新对话才能使用新连接。历史活动仍可查看草稿，不自动打开表单。

验证：拒绝凭据/权限伪造与跨scope访问，零Runtime dispatch；浏览器点击前零连接POST，预填字段、密码空白/TLS启用，手动保存后新连接可选择。
