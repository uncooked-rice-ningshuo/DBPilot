# 所选结果分析进入 Agent

移除工作台独立的分析聊天状态。用户点击“新对话分析当前结果”时启动建议模式Agent，仅授权结果所属连接；可使用输入框自定义分析要求。共享请求DTO携带精确executionId/connectionId/setId，由Runtime计划记录核对归属与完成状态。

get_selected_result严格无参数，只读已绑定快照前50行，保留截断标志与执行ID；工具不拥有原执行，不能取消用户查询。过期返回410且不调用模型，不重新执行SQL。分析回答、工具证据、取消和后续对话共用Agent历史。

验证：真实SQLite写入一次后分析快照，计数仍1；拒绝未授权连接与目标伪造；TTL后新分析410、模型调用不增；UI新对话移除旧分析、历史可恢复。
